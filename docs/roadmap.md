# Roadmap — Qanunora

## v1.0 (Current — Phases 01–30)

All 30 phases completed:
- Full legislative lifecycle management
- 11-provider AI abstraction layer
- Semantic search and RAG assistant
- Audit readiness and compliance
- Security hardening

- [ ] PDF export using `pdfkit` or `puppeteer`
- [ ] Excel export using `exceljs` (full `.xlsx`)

- [ ] Arabic RTL layout support across all frontend pages
